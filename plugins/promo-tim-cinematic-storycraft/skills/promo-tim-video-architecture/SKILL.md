# 技术影像叙事架构

先调用 `promo_get`，仅在当前 capsule 请求 `tim-cinematic-video-architecture` 时通过 `promo_guidance` 加载完整指导。

在锁定的时长、主张和证据边界内选择一个故事引擎。每个 beat 只承担一个核心工作：提出问题、建立条件、观察行动、展示证据、解释转折或收束到人的决定。让真实屏幕、实拍操作、环境声、停顿和口播各自承担必要职责。

不要照搬创作者的固定镜头节奏、音色、片头、标题或文案。无证据的强结论必须回退为问题、观察或待验证假设。只按当前 capsule 的提交契约输出，不进入剪辑或导出。
