# Promo Delivery Contract

The local Promo Workflow MCP owns the canonical delivery template. Start with
`promo_get`, then call `promo_guidance` for `promo-deliverable-exemplars` and
read the `video-delivery-contract` resource before drafting or reviewing any
video pre-production deliverable.

Use the template's exact sections, field angles, trace IDs and acceptance
checks. Replace only project facts and production choices. Do not omit a
section by writing “see master”, “as needed”, or an equivalent shorthand.

The required chain is:

`outline beat -> storyboard shot -> spoken line -> CAM/VO/MIXED task -> source material -> reusable fragment -> usage -> acceptance`

If the chain breaks, repair the upstream source document or flag a blocking
gap. Do not compensate with a vague claim, decorative graphic, fabricated UI,
or an untracked production task.

The plugin is a reasoning aid. It does not advance workflow state or replace
the MCP's requested submission shape, revision control or locks.
