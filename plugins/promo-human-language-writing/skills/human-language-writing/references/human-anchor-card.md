# 人话锚点卡

在起草或大改前先填这张卡。不能填的字段不要用通用文案补齐，写成“待补”并决定是否需要向用户追问。

```text
说话的人：
真实身份/关系：
目标读者：
读者此刻的具体场景：
场景里的卡点或张力：
作者实际观察到的细节：
产品/行动做了什么：
可以核验的结果：
作者的判断：
读者要改变的一个判断：
下一步行动：
明确不能声称的内容：
```

## 合格标准

一张合格的锚点卡至少有：一个读者场景、一个动作、一个观察细节、一句作者判断和一个证据边界。缺少其中任意一项，先补事实或缩小主张，再开始抛光。

## 最小追问

优先问能改变整段表达的问题：

- “你当时具体看到了什么状态或结果？”
- “这件事发生在什么操作、时间或限制下？”
- “这是你亲自做过的，还是根据材料得出的判断？”
- “读者看完只需要改变哪一个判断？”

不要用一次追问索要完整人生故事；一个准确细节通常比一段虚构的情绪更有用。
